# **App Name**: OFELIA

## Core Features:

- Document Type Toggle: A 'Segmented Control' type selector that allows users to choose between 'DNI' and 'RUC' for identification.
- Dynamic Input Field Adaptation: Adjusts the 'Número de Documento' input field's placeholder text and maximum length (8 for DNI, 11 for RUC) based on the selected document type.
- User Data Input Form: Provides fields for document number, full name/company name, email, and mobile phone number for user registration or login.
- Institutional Branding and Navigation: Displays the MTPE Perú institutional logo, application title, an introductory message, and a full-width action button to create a profile or log in.
- DRTPE Initiative Footer: Presents a footer acknowledging the 'Iniciativa de la DRTPE - Innova Región 2026' with appropriate small text styling.

## Style Guidelines:

- Background color: Pure white (#FFFFFF) to ensure a clean, professional aesthetic.
- Primary (accent) color: Institutional Red (#D91E18) for key actions and branding elements, conveying importance and institutional identity.
- Main text color: Dark Gray (#1A1A1A) for optimal readability and a sleek, professional look against the white background.
- Accent color: Desaturated Gold (#E8C27A), an analogous hue to the primary red, used for subtle highlights or secondary interactive elements to complement the institutional palette.
- Font choice: 'Inter' (sans-serif) for all text elements. Its modern, neutral, and highly readable characteristics align with the clean, governmental, and professional style requirements.
- Use minimal, clean, and functional sans-serif style iconography if needed for toggle controls or form validations, ensuring consistency with the professional tone.
- Mobile-First approach with all elements featuring a consistent 8px border-radius, presenting a clean, modern, and cohesive interface on small screens. Centered elements and full-width components where appropriate for clarity and ease of use.
- Subtle, professional transitions on interactive elements like the document type toggle to provide clear visual feedback without distracting from the governmental style.
